## Findings

1. Bare sibling import — `encode.py:9` does `from eda import is_missing`, which only resolves because the test shim puts `code/` on `sys.path` (`tests/test_data_prep.py:14`). This is the Day-9/Day-14/Day-17 shape again and a step back from the Day-19 all-relative-import fix. Prefer `from .eda import is_missing` (or a documented path note) so the module imports from any cwd.
2. Bare `except` — `encode.py:26` uses `except :` around `float(...)`. Catch the narrow failure (`except ValueError:`) so `KeyboardInterrupt`/`TypeError` bugs are not swallowed and the message at `:27` stays truthful.
3. `== None` relapse amid correct usage — `encode.py:56` has `if column[i] == None`, while `eda.py:49` and `encode.py:47` correctly use `is None`/`is not None`. Make `:56` `is None` for consistency.
4. `range(len(...))` indexing — `encode.py:21` (`for i in range(len(column))`) and `encode.py:55` (`for i in range(len(column))`). The first is `enumerate(column)`; the second is a comprehension/new-list build rather than index-assign.
5. Duplicated logic siblings could share — `eda.py:76` re-spells `value is None or value.strip() == ""` instead of calling `is_missing` defined 30 lines above; `encode.py:77-81` and `:101-106` both build first-seen order (the second just also keeps `seen`/`category_to_idx`). Extract one `_first_seen(values)` helper. Related: `fill_mean`'s all-missing guard at `:47` tests `None`/`""`/NaN, but `clean_col` at `:50` filters only `is not None`, so the two disagree on what "missing" means.
6. In-place mutation surprise — `encode.py:55-59` overwrites the caller's `column` list and then returns that same object (`return column, mean`). Either build a new list or document "mutates in place" in the docstring; returning the same aliased list invites double-fill bugs.
7. Message wording/typos and voice drift — `eda.py:95` `"lavels is empty"`, `eda.py:108` and `encode.py:72,97` `"vlaues is empty"`, `encode.py:27` `"its not an numeric value on row {i}"` (grammar + index with no column context). Also redundant `if not rows or len(rows) == 0` at `eda.py:63` (`not rows` suffices).

Whitespace/leftover cleanup — space-before-comma/colon at `eda.py:19` (`open(path ,`), `:20` (`reader  =`), `:75` (`idx , value`), `:113-115` (`"count" :`), `encode.py:51` (`mean  =`), `:59` (`return column , mean`); 3-4 blank lines between functions (`eda.py:38-42,80-87`, `encode.py:31-35`) vs. PEP 8's two.
